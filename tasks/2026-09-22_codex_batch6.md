## 四条口径红线（本批最容易错的地方）
1. **所有窗/平滑一律用时间单位**（BSM2 与 BSM1 都是 96 点/天）。我们今天又栽过一次：脚本里写「平滑 3 日」实际只平滑了 3 个采样点（45 分钟）。
2. **三种阈值口径不得混用**：① 参考域 0.999 分位（路线 B 上 = 13.149）；② 零误报（整条健康轨迹最大分 × 1.02，路线 B 上 = 19.560）；③ 自适应通道 0.999 分位。
3. **含噪结论必须报「多噪声实现的中位 + 区间 + 健康轨迹误报次数」**，不许用单条噪声实现。
4. **对拍法的零阈值是极值统计量**：健康-健康零分布的对数越多阈值越保守（4/8/12 对 → 2.101 / 2.434 / 2.434，延迟 12.88 / 13.36 / 15.07 天）。核对时请写明你用了多少对。
