# BSM1 雨/暴雨冲击工况报告（DSH，2026-09-20）

三种进水模式各跑健康 + 退化两条 120 天轨迹，退化配置相同（第 20 天起 KLa 衰减至 40%、100 天斜坡）：

- R1 干天循环：dryinfluent 14 天块循环；R2 干+雨循环：dry 14 天 + rain 14 天交替；

- R3 干+雨+暴雨：在 R2 基础上每 28 天周期第 20-22 天插 2 天暴雨（ASM1 溶质+TSS 乘 0.4、流量乘 2.5）。

**数据处理（必须记录）**：随包 raininfluent.csv 的 Q 列比 dryinfluent.csv 小 1000 倍（同为第 0 行：dry=21474 m3/d、rain=21.47），且 Q 列第 996 行为 NaN；直接喂入会让水力为负并报 splitter 错误。脚本内统一乘 1000 并线性插值补齐。

## 2. 结论

**① 雨/暴雨工况下「健康运行 0 误报」完全不再成立**：冻结通道误报 26 / 18 / 26 次（120 天），自适应通道 2 / 4 / 1 次；对照 BSM2 动态进水 A 窗为 2 / 0。与 18.2 的刀锋边缘、18.3 的跨工况不稳健一致——冻结通道的零误报是特定工况的巧合。

**② 自适应通道在干天循环与暴雨工况下完全漏检**（R1、R3 无自适应告警），只在 R2 报出。

**③ 检出延迟仍由工况成分主导**：同一退化配置下为 37.45 / 2.44 / 0.04 天，差异来自进水模式而非退化。

**④ 分布位置统计量的可分离性**：健康 vs 退化的滚动 5 天中位数见上表两列。

## 3. 局限

- 暴雨为自建合成扰动（简单稀释），非 BSM1 官方 storm 文件（随包未提供）；

- 三种模式各只有一条 120 天轨迹；进水由 14 天块拼接，非真实季节序列。
