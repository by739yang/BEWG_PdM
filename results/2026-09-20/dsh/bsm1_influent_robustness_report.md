# BSM1 进水工况泛化报告（DSH，2026-09-20）

做法：用 BSM2 动态进水（dyninfluent_bsm2.csv，609 天）的三个 120 天窗口作为三种进水工况；每个窗口各跑健康与退化两条 120 天轨迹。

退化配置完全相同：第 20 天起 KLa 线性衰减至 40%（100 天斜坡）。

## 2. 结论

**① 三种工况下都检出了退化（无漏检）**：自适应与冻结通道都在每个窗口报出告警。

**② 但「120 天 0 误报」不跨工况成立**：健康运行误报 A 2/0、B 6/4、C 2/3（自适应/冻结）——与 18.2 的刀锋边缘结论一致，冻结通道的零误报只在 A 窗成立。

**③ 检出延迟由工况成分主导**：同一退化配置的检出延迟为 20.24 / 30.05 / 3.28 天，差别主要来自进水工况本身。

**④ 绝对危险阈值不可用**：B、C 窗的进水工况使健康运行的 SO3 本底降到 1.01 / 0.61 mg/L，健康运行本身就长期满足 SO3<0.5 mg/L，于是「失效点」与「提前量」在该工况下完全失真（表中 B/C 的提前量为负）。

## 3. 第五条设计原则

**危险/失效阈值必须按该工况自身的健康基线标定（相对劣化幅度或分位数），不能用绝对值。**

## 4. 局限

- 三个窗口取自同一条动态进水序列（同一厂的不同时段），不是三座不同的厂；

- 未包含雨天/暴雨冲击工况（BSM1 raininfluent 需自行拼接，留作后续）；

- 每个窗口仍只有一条轨迹，未做多随机种子重复。
