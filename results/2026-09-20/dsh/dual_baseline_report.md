模块：src/dsh/dual_baseline.py。两通道各自校准、分别输出报警流并标注来源。

**注意**：本模块是演示/验证用实现，其默认参数与冻结流程 docs/PROTOCOL_v1.5.md 并不完全一致。

BSM1 存在明显的**启动暂态**：SO5 均值 0.40（第 0-20 天）-> 1.03（第 60-80 天），污泥浓度 2.06 -> 2.66。

把第 0-10 天当冻结参考时阈值被压到 4.4，健康运行 120 天报出 75 次误报；改用稳态段（第 30-45 天）参考后阈值 20.2，健康运行 0 误报。

退化运行若把冻结参考窗取在退化开始之后（第 30-45 天），参考窗自身吸收退化 -> 0 告警；这从反面确认冻结参考必须取自已确认健康的历史段。

以稳态段为参考时，退化运行的分数中位数随 KLa 衰减单调抬升（2.15 -> 2.29 -> 2.44 -> 2.95），健康运行平稳（2.00 -> 2.07 -> 1.91 -> 2.02）；

但 p99.9 单点阈值（20.2）远高于这一平移量，因此单点事件机对慢漂移只能靠瞬态越限捕捉（1 次，延迟 20.3 天）。

滚动 5 天中位数偏移判据在健康运行 0 误报，但在本案幅值/斜率下要到第 101 天才越限 -> **慢漂移的可检测时间受信噪比限制，不是判据形式问题**。

## 5. 本模块给出的三条设计原则

1. 双基线并行：短窗自适应抓突变（对慢漂移免疫），冻结基线抓慢漂移（对突变不够灵敏）。

2. 冻结参考域必须取自"验收合格且已进入稳态"的历史段；投运暂态段会把阈值压得过低，导致长期误报。

3. 工况条件化对两条通道都是必需的（MetroPT-3 按负荷/启停分层，BSM1 按一天中的时段分层）；分层后剩余漂移才是可判读信号。

## 6. 局限

- MetroPT-3 的冻结参考窗取投运后前 10 天，其有效性同样依赖该段处于稳态；本数据集上误报率可接受（0.0181 次每全稳定小时）。

- 冻结基线在数月尺度上会因工艺自身演化而失效（本模块未实现再锁定/带迟滞后刷新），属后续工作。

- BSM1 退化场景只有一档（KLa 衰减至 40%、60 天斜坡），检测延迟随幅值/斜率变化的关系尚未系统扫描。
