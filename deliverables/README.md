## 三、交给评委前必须先补的三处（目前是占位）

1. **团队与联系方式**：PPT 与说明书里的 <姓名> <电话> <邮箱> <指导老师> 全部要填；
2. **市场数据原文核实**：年鉴存量基数（约 4816 座）与上市公司年报的维修/大修科目，需核对原文并标注出处；
3. **成本参数**：失效代价 / 计划更换 / 剩余寿命折算三项，需企业渠道；**未标定前所有金额保持"占位值"口径，不得对外给数**。

## 四、口径纪律（见 docs/08）

- 可以对外：SKAB 零偏差、真实空压机 214 天 105 个告警、诊断同记录/跨转速 1.000、RUL RMSE 15.27、设备级比值通道 9.80 天（区间 5.03–11.03）；
- 必须带限定：MetroPT-3 的 2/4 要说明"标签辅助选点"；BSM1/BSM2/污泥线一律标"机理仿真"；省 16% / 24.5% 要标"成本占位"；
- 不可以说：已在污水厂现场验证、有客户订单、能省多少钱、"0 误报"。
