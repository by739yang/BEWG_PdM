# PROTOCOL_v1 —— SKAB 基准统一协议（冻结候选）

状态：**由 DSH 提出，等待 Codex 确认**。确认后本文件不再改动；如需改动，另出 v2 并写明原因。
生效日期：2026-09-15 ｜ 适用数据：SKAB（1 Hz）

## 0. 目的与不变量
目的：让两个独立实现产生**可比、可审计**的数字。
不变量：**只能改变第 5 节的打分函数**，第 1~4、6~8 节双方必须完全一致。

## 1. 数据
- 带标签文件：data/SKAB-master/data/{valve1,valve2,other}/*.csv（34 个）
- 全正常文件：data/SKAB-master/data/anomaly-free/anomaly-free.csv（仅"全局迁移"路线使用）
- 行序即时间序，采样 1 Hz；标签列 anomaly、changepoint 只允许出现在第 7 节（评估）中。

## 2. 预处理（严格因果，逐文件、逐信号）
对第 j 路信号 x，在时刻 t 只用 x[lo:t)：
- W = 120；lo = max(0, t-W)；若可用样本 < 45，则用 x[0:min(45,N)) 兜底（冷启动）
- med(t) = median(x[lo:t))；iqr(t) = q75 − q25
- scale(t) = max( iqr(t)/1.349, 0.02 × |med(t)|, 1e-9 )
- z_j(t) = (x_j(t) − med(t)) / scale(t)
理由（实测）：流量信号 IQR≈0.004、中位数≈32.0。若尺度下限取 0.1%×|med|，抖动仍被放大到约 5σ；取 2% 后降到约 0.25σ。退化传感器真实存在，必须挡住。

## 3. 特征
对每个 t，取最近 60 秒的 z（不足 60 个则用已有样本，至少 10 个）：
last, mean, std, min, max, slope(最小二乘斜率，单位 1/s)
→ 8 路 × 6 = **48 维**。（此为 Codex 提出的定义，DSH 按此重写以实现一致。）

## 4. 标定期（取代"文件前 40%"）
cal = [120, min(120 + 1800, N // 2))
- 与文件长度解耦（固定 30 分钟上限）、无标签、双端均由规则确定
- 若 cal 样本数 < 300 → 该文件标 insufficient-cal，不计入主表，单独列出
- 事后诊断（不影响流程）：报告 cal 段内故障标签占比，>0 的文件在结果表中置 flagged=1

## 5. 打分函数（唯一可变化部分）
- F0 阈值法：score = max_j |z_j(t)|（用第 2 节的标准化信号，不用 48 维）
- F1 马氏距离：cal 上估计均值与协方差（岭 +1e-3），score = sqrt((f−μ)ᵀ Σ⁻¹ (f−μ))
- F2 PCA-SPE：cal 上拟合 PCA 保留 90% 方差，score = ‖f − reconstruct(f)‖₂
- F3 变点：score = max_j |mean(z[t−360:t−60]) − mean(z[t−60:t])| / (std_a + std_b + 1e-3)
- F4 自编码器：1D 卷积，仅在 cal 上训练，score = 重建误差（窗口最后时刻）

## 6. 判决（事件化，取代"块内任一点"）
- 候选越限：score(t) > thr，thr = cal 上 score 的 0.995 分位
- 进入告警：连续 CONSEC_IN = 10 个样本越限
- 退出告警：连续 CONSEC_OUT = 30 个样本低于 0.8 × thr
- 冷却：一次告警事件结束后 COOLDOWN = 300 s 内不再新开事件
- 输出：告警事件列表 [(t_start, t_end)]
说明：此规则修掉"逐秒 0.5% 分位 + 60 s 块任一点即报警 ⇒ 块误报率约 26%"的算术缺陷。

## 7. 指标
- **事件召回**：真值事件（连续 anomaly=1 且长度 ≥60 s 的段）中被任一告警事件覆盖（区间相交）的比例
- **独立误报事件 / 健康小时** = 未与任何真值事件相交的告警事件数 ÷ (健康样本数 / 3600)
- **健康时间报警占比** = 报警状态样本数 ÷ 健康样本数
- **检测延迟中位** = 告警事件起点 − 真值事件起点（仅命中事件）
- **DET 曲线**：阈值取 cal 分位 {0.90, 0.99, 0.995, 0.999}，横轴=误报事件/健康小时，纵轴=事件召回
- F1 只作附注，且必须同时给出"恒报正类"的平凡基线
