## 三、铁律（不因加量而放松）
1. 不许编数据；仿真一律标注仿真；所有数字附可复现命令；
2. 数字没进 PROJECT_STATE 的结论区，不得用于任何对外材料；
3. 每个模块都要有「另一套独立实现」的复核记录，做不到的必须写明「未复核」；
4. 加量不等于降质：宁可某个模块当天没做完，也不交一个说不清来历的数字。
