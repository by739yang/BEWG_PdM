# 06 复现指南

> 目的：任何人（包括明天的我们自己）拿到这个仓库，能在 15 分钟内把关键结论重跑一遍。

## 一、环境
    python -m pip install -r requirements.txt
Python 3.12 实测通过。GPU 非必需（Torch 只在早期自编码器实验里用过）。

## 二、一键复现
    python run_all.py            # 快速链路，约 2-4 分钟
    python run_all.py --full     # 全量，约 10-15 分钟（含 SKAB 协议、RUL 训练、诊断实验）
    python run_all.py --only metric

快速链路包含：MetroPT-3 冻结口径评估 → 端到端链路 → 一致性自检 → 生成演示页。
全量额外包含：交互式数字孪生演示台 → SKAB 冻结协议 → C-MAPSS RUL → 诊断跨记录/归一化 → 双基线检测模块（MetroPT-3 + BSM1）→ 材料四图 → BSM1 闭环四图。
**收工前必跑**：一致性自检（30 秒）能抓出"文档数字与结果文件不符"这类问题。

## 五、纪律（写给自己看）
1. 数字没进 PROJECT_STATE 第 12/15/16 节，不得写进材料；
2. 成本参数为占位值，任何金额不得对外引用；
3. 改口径必须同时改文档与脚本，并跑一次一致性自检；
4. 任何"待复核"标记的数字，必须由第二套独立实现确认后才能去掉标记。
