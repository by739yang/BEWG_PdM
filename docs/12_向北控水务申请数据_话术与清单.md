# 12 向北控水务申请数据集：话术、清单与合规

> 用途：向命题方 / 组委会 / 北控水务争取**真实污水厂设备数据**（哪怕很小一段），把作品从「仿真验证」推进到「真实厂试点」。
> 原则：**只问一次、只问一个人、留邮件痕迹；先要最小可用数据集，别一上来要全厂数据。**

## 一、走哪条渠道（按优先级）
| 优先级 | 渠道 | 说明 |
|---|---|---|
| 1 | **大赛官方邮箱 cxcy@bewg.net.cn** | 正式、留痕、能转到命题方；抄送学校赛事联络人与指导老师 |
| 2 | **组委会联系人（命题答疑）** | 电话 / 微信先问路，再补一封邮件把口径固定下来 |
| 3 | 学校赛事联络人 | 由学校名义发函，成功率更高（附件 3 里填的联络人就是他） |
| 4 | 复赛 / 答疑会现场 | 当面申请并留联系方式，回头发邮件确认 |

## 二、要什么（最小可用数据集，按重要性排序）
**首选：1 台关键设备、连续 12 个月以上**
1. **运行数据**：时间戳 + 电流 / 功率 + 温度（轴承 / 绕组 / 油温）+ 压力 / 流量 + 转速（或导叶 / 变频开度）+ 开停状态；采样 **1 分钟最好，15 分钟也够**；CSV / Excel 导出即可；
2. **事件台账**：故障与报警记录（时间、部件、现象、处理方式、停机时长）、检修与更换记录（含备件与工时）；
3. **设备台账**：型号、铭牌参数、投运年份、大修周期；
4. **点表**（有最好）：DCS / SCADA 测点名称与单位。
**可选（拿到更好）**：非计划停机损失、计划更换费用、备件价格 —— 把「省钱测算」从占位值换成真实值。
**推荐设备**（按价值与数据可得性）：**鼓风机 / 污泥脱水机 / 提升泵 / 回流泵**。
**降级方案（对方为难时给台阶）**：只给 3–6 个月 + 一次故障前后数据；或只给脱敏统计特征；或只开放 1 台设备做试点。

## 四、别做这五件事（会直接把路堵死）
1. 别一上来要「全厂所有历史数据」——对方会直接拒绝；
2. 别承诺「能帮你们省 XX 万」——我们的成本参数是占位值，说了就是夸大；
3. 别说「要训练大模型」——现场听到「大模型」只会想到算力、隐私与合规风险；
4. 别多头问（同时找多个人）——显得不专业，也容易让对接人尴尬；
5. 别先给未脱敏材料——对方想看演示时，只发已公开的样例报告与演示页链接。

## 五、如果拿不到数据怎么办（不影响参赛）
1. **公开真实数据已够技术分**：SKAB（真实水泵台架）+ MetroPT-3（真实空压机，105 个真实告警）；
2. **仿真就标仿真**：BSM1 / BSM2 链路上所有结论都写明「机理仿真」，并把适用边界写清楚；
3. 请对方给一份**脱敏样例**（哪怕 1 天数据）用于演示「接入 → 体检 → 标定 → 报告」这条链路；
4. 退一步争取**试点意向**（一页 POC 方案 + 明确验收口径），材料里写成「已完成现场接入准备，等待试点」；
5. 这些都是诚实且可被追问的表述，比硬编数据安全得多。

## 六、拿到数据后的第一件事（流程已备好）
1. python run_lanmai.py serve --open（本地工作台）；
2. 上传「健康期」数据 → 标定基线（工具会告警参考窗是否有趋势，需人工确认该段确无检修 / 故障）；
3. 上传「待监测」数据 + 基线 → 出企业版报告（体检 / 标定 / P1·P2·P3 / 四图 / 局限）；
4. 用事件台账核对「真实故障时间」与「首报时间」，算提前量，写进材料 —— 这是最有说服力的一段。
