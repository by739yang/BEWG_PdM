## 2. 预处理（严格因果，零未来信息）
- t = 0：z = 0（不读取任何未来值，**不再使用 x[0:45) 兜底**）
- t >= 1：win = x[max(0, t-120) : t)（不含当前点）
  - med = median(win)（逐信号）
  - iqr = q75 − q25
  - scale = max( iqr/1.349, 0.02 × |med|, 1e-9 )
  - z_j(t) = ( x_j(t) − med_j ) / scale_j
- 标签不得进入预处理。

## 3. 特征（48 维）
- 每个 t 取窗口 Zwin = z[max(0, t-59) : t+1]（**包含当前点**）
- 六个统计量：last、mean、std(**ddof=0**)、min、max、slope
- slope：对 0..m−1（m 为窗口实际长度）做**含截距最小二乘**的斜率，单位 1/s
- 8 路 × 6 = 48 维

## 4. 标定期（固定 360 s，删除 N/2 上限）
    cal_start = 120
    cal_end   = min(480, N)
    cal       = [cal_start, cal_end)
    cal_end - cal_start < 300 → insufficient-cal，不计入主表
- 事后诊断（不影响流程）：cal 内标签为正的样本数 > 0 → flagged = 1
- 依据：与 F3 的 360 s 回看范围一致；不随 N 移动；SKAB 上仅 other/2.csv 受污染（其首个异常行号 104 < 120，任何无标签规则都无法避开）

## 5. 打分函数（唯一可变部分）
- **F0 阈值法**：score = max_j |z_j(t)|（用第 2 节标准化信号，不用 48 维）
- **F1 马氏距离**：cal 上估计均值与协方差（岭 +1e-3），score = sqrt((f−μ)ᵀ Σ⁻¹ (f−μ))
- **F2 PCA-SPE**：PCA(n_components=0.90, svd_solver='full')，**只用 PCA 自带中心化、不额外缩放 48 列**；score = 在原特征坐标中的重构残差 L2
- **F3 变点**：A = z[max(0,t−360) : t−60]，B = z[t−60 : t]，**从 t=120 起**打分；两段 std 取 ddof=0；score = max_j |mean(A)−mean(B)| / (std(A)+std(B)+1e-3)
- **F4 自编码器**：1D 卷积，仅在 cal 上训练，score = 窗口最后时刻的重建误差

## 6. 阈值与事件判决
- 阈值：thr_q = score 在 cal 上的 q 分位（**线性插值**）。主阈值 q=0.995；DET 扫描 q ∈ {0.90, 0.99, 0.995, 0.999}，**状态机参数不变**
- 状态机**在 eval_start 处清零后运行**，只统计 eval 窗内事件
- 进入：连续 10 个样本 score > thr，第 10 个样本记为 t_start
- 退出：连续 30 个样本 score < 0.8 × thr，第 30 个样本处理完毕后退出，t_end = t+1
- 未退出则 t_end = N
- 冷却：[t_end, t_end + 300) 内不累计新的进入计数
- 输出：告警事件列表 [(t_start, t_end))

## 7. 指标（四项成组报告，缺一不可）
评估窗内真值事件 G = [g0, g1)：连续 anomaly=1 的段**裁到 eval 窗之后**长度 ≥ 60 s。
- **命中**：存在告警启动时刻 s ∈ [max(eval_start, g0−60), g1)；delay = s − g0（取最早合格 s）。合法负延迟仅为 [−60, −1] s
- **事件召回** = 命中真值数 / 真值总数
- **独立误报事件 / 健康小时**：告警**启动时刻** s 落在健康样本上（y[s]=0）且该告警不属于任何命中 → 计 1 次；分母 = eval 内健康样本数 / 3600
- **TIA-H（健康时间报警占比）** = eval 内"处于告警状态且 y=0"的样本数 / 健康样本数
- **命中事件延迟中位**（秒）
- 辅助诊断：too_early_overlap（启动早于 g0−60，但事件与真值重叠）——只作诊断，**不进入中性区**
- 汇总：跨文件用**分子/分母汇总**，不平均逐文件比率
- F1 仅作附注，且必须同时给出"恒报正类"的平凡基线
- 禁止：只摘取事件召回或误报事件数宣称方法更优；暂不做单一加权总分
