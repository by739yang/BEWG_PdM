4. 流程：项目初筛 → 初赛（网评）→ 复赛（看资料 + 看路演视频）→ 总决赛（现场路演）。

## 三、三个真实风险（按严重程度排序）
1. **范围过大**（最严重）：现在这条路线是"检测 → 诊断 → RUL → 排程 → 仿真 → 看板 → BP → 视频"八件事一起做。20 天做完八件、每件都做扎实，一个人加两个 AI 也悬。
2. **市场和商业化内容没有地基**：技术分 50% 我们有的聊；市场 20% + 商业模式 20% 现在完全是空的，而且**不许编**。必须去找可引用的公开数据（国家统计局、行业协会、上市公司年报）。
3. **人的环节会被卡**：报名、找指导老师、拍视频、软著登记，AI 替代不了，且都有外部周期（软著登记要 1 个月以上，10/13 前拿证基本不可能，只能拿受理号）。

## 七、一句话
**20 天做完"八件事"不可能；做完"三件事"（可信的检测证据 + 能讲清的决策价值 + 一份完整材料）完全可能。**
比赛看的不是我们做了多少实验，是这份材料能不能自圆其说、经得起追问。**把范围砍小、把证据做硬、把话说实**，这是我们现在唯一的正确打法。
